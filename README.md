# Contextual Reader project page

This folder is a self-contained static project page. It follows the centered academic layout used by Omer Dahary's recent project pages, with paper-specific colors and figures. The comparison gallery includes 20 six-way Fine-T2I comparisons extracted from the paper at their original embedded resolution.

## Preview

Run a local web server from this folder:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Before publishing

1. Replace `Preprint · 2026` with the venue, if applicable.
2. Replace the local `paper.pdf` link with the final arXiv URL after submission.
3. Enable the code button when a public repository is available.
4. Update the BibTeX entry with the arXiv identifier or venue metadata.

The included `paper.pdf` is the supplied draft and should be replaced by the corrected final build before deployment.
